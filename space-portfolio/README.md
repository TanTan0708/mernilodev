# My Space Portfolio

1. Install Node.js (nodejs.org, the LTS version)
2. In this folder run:  npm install
3. Then run:           npm run dev
4. Open the link it prints (usually http://localhost:5173)

- Edit text/projects:  src/data/portfolioData.js
- Project pictures:    public/images/
- 3D models:           src/models/   (sun.glb, mercury.glb, venus.glb, earth.glb, mars.glb,
                       jupiter.glb, saturn.glb, uranus.glb, neptune.glb, island.glb,
                       astronaut.glb, spaceship.glb)
